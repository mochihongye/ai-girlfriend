# 💗 我的 AI 女友 · 小念

一个基于 **Ollama 本地大模型**构建的 AI 女友项目，能像真人一样和你微信聊天、主动关心你、记得你们之间的点滴，还会用温柔的声音和你说话。

> 所有对话都在你本地完成，模型不出本机，隐私安全。

---

## ✨ 功能特点

- **🎀 人设与陪伴**：一个温柔、体贴、会撒娇、有自己小情绪的 AI 女友「小念」，句子简短自然，像真人微信聊天。
- **💬 本地聊天界面**：内置聊天软件风 GUI（原生窗口，无需浏览器），左侧联系人、右侧对话气泡，随时能聊。
- **📱 微信接入**：桌面自动化监听微信，对方发消息她会自动回复，支持多个联系人、按联系人切换语气。
- **🎙️ 语音交互**：支持发/收语音（本地 Whisper 识别 + 微软 edge-tts 温柔声线合成）。
- **🧠 长期记忆**：自动记住你们的对话和习惯，并定期总结成长期记忆，越聊越懂你。
- **🐾 桌面桌宠**：呼出一个有动漫形象、可拖动、带轻盈浮动动画的桌宠，双击快捷方式/随手就能想起她。
- **👥 联系人管理**：界面里直接添加联系人；每个联系人可以单独调参数（身份、称呼、语气、性格等），没特调的统一用默认参数。
- **🎨 多主题**：内置粉樱暖阳、暗夜紫火、薄荷奶咖、雾蓝海盐四套界面皮肤。
- **💌 主动关心**：在你们很久没聊时，她会适当主动发一条消息找你。

## 🧱 项目结构

```
├── gui.py                 # 聊天软件风主界面 + 独立小窗 + 桌宠
├── brain.py               # AI 大脑：对话生成、人设切换、记忆调用
├── memory.py              # 长期记忆存储（SQLite）
├── contact_manager.py     # 联系人管理与每用户可调参数
├── main.py                # 配置加载、Ollama 连接、语音管道装配
├── wechat_auto_bot.py     # 微信接入（桌面 UI 自动化，适配 3.x/4.x）
├── voice_tts.py           # 文字转语音（edge-tts，含多音字与文本清洗）
├── voice_stt.py           # 语音转文字（本地 Whisper）
├── utils_audio.py         # 音频格式处理（silk/wav 转码等）
├── local_chat.py          # 本地终端聊天入口
├── config.example.yaml    # 配置示例（真实配置 config.yaml 不上传）
└── requirements.txt       # Python 依赖
```

## 🚀 快速开始

### 1. 环境准备

- Python 3.10+（Windows）
- 本地安装并运行 [Ollama](https://ollama.com)，拉取聊天模型，例如：

```bash
ollama pull qwen2.5:7b
```

- 如需要语音/微信功能：安装微信 PC 版（保持登录、窗口打开即可）。

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 配置

```bash
# 复制示例配置并修改
cp config.example.yaml config.yaml
```

主要配置项都在文件里注释说明：人设、联系人、模型、语音、主动消息频率等。

### 4. 启动

```bash
# 桌面版（推荐）
python gui.py

# 纯本地终端版（不连微信）
python local_chat.py
```

## 📖 使用说明

| 功能 | 入口 |
| --- | --- |
| 添加（微信）联系人 | 主界面左侧「＋ 添加」|
| 每个联系人的个性化参数 | 顶栏「👥 联系人」|
| 记忆 / 日志 / 设置 | 顶栏对应图标 |
| 呼出桌宠 | 顶栏「🐾 桌宠」|

> 微信自动化会扫描左侧聊天列表，发现监听联系人（`wechat.watch_list`，第一个为主对象）有新消息即切过去回复。聊天全程保持微信窗口打开（可最小化）。

## 🙏 所用开源技术

本项目站在优秀的开源生态之上，主要使用：

| 用途 | 技术 |
| --- | --- |
| 本地大模型推理 | [Ollama](https://ollama.com) |
| 对话模型 | [Qwen2.5](https://github.com/QwenLM/Qwen2.5)（开源）等，可随意换 |
| 文字转语音 | [edge-tts](https://github.com/rany2/edge-tts)（微软语音服务）|
| 语音识别 | [faster-whisper](https://github.com/SYSTRAN/faster-whisper)（Whisper 加速版）|
| 微信桌面自动化 | [pywinauto](https://github.com/pywinauto/pywinauto) |
| 界面 | Tkinter（Python 标准库）|
| 记忆存储 | SQLite |

> 模型、音色、依赖均可按需替换，不影响整体结构。
